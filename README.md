# Auto Fish

Панель для **Adobe Premiere Pro**, которая режет секвенцию по разметке редактора.

Редактор берёт транскрипт реплик (выгруженный из Premiere) в Word и **выделяет
заливкой** всё, что нужно убрать. Auto Fish читает этот `.docx` вместе с
пословным JSON-транскриптом из Premiere, находит помеченные куски на таймлайне и
удаляет их (ripple), а спорные места и комментарии редактора расставляет маркерами.

Работает целиком внутри Premiere (CEP-расширение). Ничего, кроме самого Premiere,
на компьютере не нужно — ни Python, ни Node.js, ни прав администратора.

---

## Установка

Нужен только установленный **Adobe Premiere Pro** (2019+). Ни Python, ни Node.js,
ни прав администратора.

### Просто (рекомендуется)

1. Скачать **`AutoFishSetup.exe`** со страницы
   [**Releases**](https://github.com/keriklamar/auto-fish/releases).
2. Закрыть Premiere Pro, запустить `AutoFishSetup.exe`, нажать «Далее».
3. Открыть Premiere → меню **Window → Extensions → Auto Fish**.

Удаление — через «Установка и удаление программ» → «Auto Fish».
Обновление — просто запустить новый `AutoFishSetup.exe`.

### Вручную (без установщика)

1. Скачать/распаковать репозиторий целиком (в архиве уже всё нужное).
2. Закрыть Premiere Pro, запустить `install.bat`.
3. Premiere → **Window → Extensions → Auto Fish**. Удаление — `uninstall.bat`.

Оба способа кладут панель в `%APPDATA%\Adobe\CEP\extensions\auto_fish` и включают
`PlayerDebugMode` в реестре текущего пользователя (разрешает Premiere грузить
неподписанное расширение).

## Рабочий процесс

### 1. Рыба-мейкер: транскрибация и два экспорта

1. Открыть нужную секвенцию, панель **Text** → **Transcribe** (выбрать язык,
   при желании — распознавание спикеров).
2. **Экспорт для редактора.** В панели Text → кнопка «**•••**» → **Export** →
   текстовый формат. Открыть полученный файл в Word и сохранить как `.docx`.
   Отдать редактору. Таймкоды и строки `Speaker 1/2/…` — **не трогать**.
3. **Экспорт для панели.** Там же: «**•••**» → **Export** → **JSON**. Сохранить
   рядом с `.docx`. Этот файл содержит пословные тайминги — по нему панель находит
   точные границы кусков.

> Прямо из проекта транскрипт панель достать не может (Premiere не даёт к нему
> доступа через скрипты), поэтому JSON выгружается вручную — один раз на проект.

### 2. Редактор: разметка `.docx`

Смотри отдельный раздел ниже — **[Как размечать текст](#как-размечать-текст-для-редактора)**.
Его можно скопировать и отдать редактору как есть.

### 3. Рыба-мейкер: резка

1. Открыть в Premiere секвенцию **в исходном, ещё не порезанном виде**.
   Для страховки можно сделать дубль секвенции (`Ctrl+D` в панели Project).
2. Открыть панель **Auto Fish**.
3. **Шаг 1 — Файлы.** Выбрать размеченный `.docx` и `.json` (кнопками или
   перетащив оба файла в панель). Нажать **Разобрать**.
4. **Шаг 2 — Проверка.** Раскрыть секции, посмотреть что нашлось, при желании
   поправить тексты будущих маркеров и снять лишние галочки.
5. **Порезать секвенцию.** Панель удалит помеченные куски и расставит маркеры.
6. Доделать вручную то, что попало в «**⚠ Не вырезано — проверь**».

Резка идёт по **текущей** секвенции и занимает до минуты на большом проекте —
в это время Premiere трогать не надо.

## Резка по звуку (без сценария)

Кнопка **«🎙 Резать по звуку»** на первом экране. Для случаев, когда нужно убрать громкие места на конкретной аудиодорожке
(например, микрофон режиссёра), без транскрипта и сценария.

1. Укажи номер аудиодорожки (A4, A6…) и нажми **«Найти пики»** — панель через `ffmpeg` считает громкость клипов этой дорожки.
2. В окне появится **график громкости**. Тащи **горизонтальную линию порога** вверх-вниз (или впиши число: «35» = −35 дБ):
   вырежется всё, что громче линии, по всей секвенции. Красным подсвечены вырезаемые участки.
3. **«Искать соседний пик в пределах N с»**: если рядом нашёлся ещё один пик, пауза между ними тоже удаляется (одна фраза);
   если нет — тишина не трогается. Вправо автоматически добавляется фиксированный хвост ~⅓ с.
4. Проверь список диапазонов (можно снять галочки) и нажми **«Порезать по пикам»**. Резка идёт теми же пачками, что и по сценарию,
   есть кнопка «Остановить» и галочка резервной копии.

Нужен `ffmpeg` (ищется в WinGet, `FFMPEG_PATH`, `PATH`; установка: `winget install Gyan.FFmpeg`). Секвенция должна быть в исходном виде.
Код: `core/peakAnalyze.js` (decode → threshold), `host/cut.jsx afTrackClips`.

## Что означают секции на шаге 2

| Секция | Что это | Что делает панель |
|---|---|---|
| **⚠ Не вырезано — проверь** | Фрагменты, помеченные на удаление, но программа не смогла надёжно определить их границы по словам | **НЕ режет.** Ставит красный маркер `ПРОВЕРИТЬ: …` — доделать руками |
| **✍ Комментарии редактора** | Отдельные абзацы, которые редактор вписал между репликами (не внутри текста реплики) | Ставит маркер `КОММЕНТАРИЙ: …` |
| **Прочее** | Слова, написанные ЗАГЛАВНЫМИ прямо внутри реплики (СК, МОНТАЖ и т.п.), от 3 букв | Ставит маркер `ПРОЧЕЕ: …`. По умолчанию выключено |
| **Статистика** | Сводка разбора | — |

Пометки капсом **короче 3 букв** (например «СК») в маркеры не попадают — это
сделано специально, чтобы не ловить сокращения и инициалы в тексте.

## Как размечать текст (для редактора)

> Этот раздел можно отдать редактору целиком.

Тебе пришёл файл `.docx` — это транскрипт реплик из видео. Нужно пометить в нём
всё, что должно быть **вырезано** из видео.

**Что нельзя трогать:**
- строки с таймкодами (`00:01:23:10 - 00:01:27:00` и т.п.);
- строки `Speaker 1`, `Speaker 2`, `Unknown`;
- не переформатируй документ, не удаляй абзацы, не перенабирай таймкоды.

**Как пометить фрагмент на удаление:**
- выдели его мышью и нажми **Заливка текста / Выделение цветом (Highlight)** —
  та самая кнопка с жёлтым маркером на панели «Шрифт»;
- цвет **любой** — программа реагирует на сам факт выделения, не на цвет;
- **не** используй для этого зачёркивание, изменение цвета шрифта, жирный/курсив —
  их программа не видит.

**Правила:**
- нужно убрать всю реплику целиком → выдели заливкой **весь её текст**;
- нужно убрать только часть → выдели заливкой **только эти слова**;
- хочешь оставить комментарий/инструкцию рыба-мейкеру → напиши её **отдельным
  абзацем между репликами** (не внутри текста реплики). Она станет маркером
  на таймлайне, но ничего не вырежет.

**В конце:** сохрани файл как `.docx` (не `.doc`, не `.txt`) и отправь обратно.

## Привязка сценария к секвенции

Таймкоды сценария не обязаны совпадать со временем в секвенции (например, в секвенцию собрана часть сценария). Панель сама находит
сдвиг по тексту (блок сценария ищется в JSON), режет с поправкой и пропускает блоки, которых в секвенции нет (подводки, чужие семьи).
На шаге 2 в статистике видно строку «Привязка: сценарий … → секвенция … (сдвиг …)». Код: `core/align.js`.

## Для разработчика

- Ядро разбора — чистый JS в `core/` (без зависимостей от Premiere):
  `parseDocx.js` (docx → блоки/слова/подсветка), `parseTranscript.js` (JSON → слова),
  `difflib.js` (порт `difflib.SequenceMatcher`), `analyze.js` (fuzzy-мэтч частично
  помеченных блоков, сборка cut-листа), `markers.js` (пересчёт позиций маркеров под
  порезанную секвенцию), `timecode.js`, `runfiles.js`.
- `host/cut.jsx` — ExtendScript: `extract()` по диапазонам + расстановка маркеров.
- `client/` — UI панели (HTML/CSS/JS, тёмная тема Premiere).
- Проверки: `npm test` (`node spike/all.js`) — сверка ядра с зафиксированным
  эталоном на анонимизированной фикстуре `spike/fixtures/sample.*`.
- Ядро изначально было портом Python-приложения и сверено с ним байт-в-байт.
- Сборка установщика: `installer/build.bat` (нужен Inno Setup 6) →
  `installer/dist/AutoFishSetup.exe`. Кладёт в архив только то, что реально едет
  в панель (`git archive` + `export-ignore` в `.gitattributes`).
